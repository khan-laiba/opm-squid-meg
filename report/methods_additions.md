**Noise covariance.** Each array's oracle covariance is computed in closed form, without sampling: C = Σ~s~ + s² L~bg~ A L~bg~ᵀ + E Σ~e~ Eᵀ. Σ~s~ is diagonal, each channel's squared white-noise spectral density times the filter's equivalent noise bandwidth ({{ F.meth_enbw_hz }} Hz). L~bg~ holds the array's lead fields of the {{ F.meth_bg_n_sources }} independent, cortex-normal background dipoles, a greedy Poisson-disk subset of the usable white-surface vertices with {{ F.meth_bg_grid_mm }}-mm minimum spacing (seed {{ F.meth_seed_g2 }}). A = diag(a~i~), a~i~ being the area of source i's Voronoi cell on the cortex; the cells partition the {{ F.meth_bg_area_cm2 }} cm² of usable cortex ({{ F.meth_bg_mean_area_mm2 }} mm² on average). Source i's moment variance is s² a~i~, with s² = {{ F.meth_bg_var_per_mm2_nam2 }} nAm² per mm² (standard deviation {{ F.meth_bg_sd_per_sqrt_mm2_nam }} nAm × √(a~i~/mm²); {{ F.meth_bg_rms_sd_nam }} nAm root-mean-square over the sources), fitted once so that the good gradiometers' median modelled variance equals their median measured brain noise ({{ F.meth_bg_calibration_grad_ft_cm }} fT/cm RMS), and kept per unit area on every head. E holds the array's responses, through its own coil integration points, to {{ F.meth_env_terms }} external-field terms ({{ F.meth_env_uniform_terms }} uniform, {{ F.meth_env_gradient_terms }} linear-gradient, about {{ F.meth_env_r0_mm }} mm in the head frame), and Σ~e~ is their coefficient covariance, fitted to the band-filtered empty-room recording. Plug-in covariances are Ledoit–Wolf estimates from {{ F.meth_plugin10s_samples }} or {{ F.meth_plugin60s_samples }} independent samples, the 2BT equivalents of {{ F.meth_plugin_seconds }} s.

**Projection.** P = I − E(EᵀWE)⁻¹EᵀW, with W = Σ~s~⁻¹, is applied to topographies and covariance alike (Ps, PCPᵀ), by the same rule for every array. For Neuromag it acts on all {{ F.meth_squid_channels }} channels jointly, so its magnetometer and gradiometer comparisons after projection use subsets of jointly projected data. Retained ranks: {{ F.meth_rank_squid_proj }} of {{ F.meth_squid_channels }} ({{ F.meth_rank_squid_mag_proj }} of {{ F.meth_squid_mags }} magnetometers, {{ F.meth_rank_squid_grad_proj }} of {{ F.meth_squid_grads }} gradiometers), {{ F.meth_rank_dense_proj }} of {{ F.meth_dense_sites }} (dense) and {{ F.meth_rank_matched_proj }} of {{ F.meth_matched_sites }} (matched). Whitening drops eigenvalues of the correlation-normalised covariance below {{ F.meth_whiten_tol }} of the largest.

**OPM sensitive axes.** Each OPM's axis is the normal of the BEM head surface (placed on the MRI scalp, normals from its own triangles) averaged within {{ F.meth_opm_axis_radius_mm }} mm of the site. It deviates from a plane fitted to the dense MRI scalp by a median {{ F.meth_opm_axis_dev_median_deg }}° ({{ F.meth_opm_axis_dev_pctl }} percentile {{ F.meth_opm_axis_dev_p95_matched_deg }}° matched, {{ F.meth_opm_axis_dev_p95_dense_deg }}° dense). With the earlier axes, the adult's stored outer-skin normals (within {{ F.meth_opm_axis_radial_deg }}° of radial), at the same sites, the projected dense ratio is {{ F.meth_hse_radial_dense_proj_ratio_3dp }} {{ F.meth_hse_radial_dense_proj_ci_3dp }} instead of {{ F.meth_hse_final_dense_proj_ratio_3dp }} ({{ F.meth_hse_radial_dense_proj_45_70_ratio }} instead of {{ F.meth_hse_final_dense_proj_45_70_ratio }} at {{ F.meth_hse_deep_lo_mm }}–{{ F.meth_hse_deep_hi_mm }} mm): nearly radial axes make room-field patterns resemble those of deep sources, so the projection removes more of their signal (with sensor plus brain noise, unprojected: {{ F.meth_hse_radial_dense_ib_ratio_3dp }} against {{ F.meth_hse_final_dense_ib_ratio_3dp }}).

**Neuromag system.** The model combines the sample recording's VectorView geometry ({{ F.meth_squid_mags }} magnetometers, {{ F.meth_squid_grads }} planar gradiometers), MNE-Python's T3 coil definitions (types {{ F.meth_coil_grad_type }} and {{ F.meth_coil_mag_type }}, as listed for the MRN system; accurate integration over {{ F.meth_coil_grad_points }} points per gradiometer and {{ F.meth_coil_mag_points }} per magnetometer) and the manufacturer's typical white noise of the TRIUX system, {{ F.meth_squid_mag_asd }} fT/√Hz and {{ F.meth_squid_grad_asd }} fT/(cm √Hz) ({{ F.meth_squid_mag_rms_ft }} fT and {{ F.meth_squid_grad_rms_ft_cm }} fT/cm in the band). These values, like the {{ F.meth_dewar_mm }}-mm coil-to-helmet spacing, are transcribed, not verified against the specification sheet, which was not available: a representative Neuromag system, not one installation. Noise from the measured empty-room spectrum ({{ F.meth_squid_meas_mag_rms_ft }} fT, {{ F.meth_squid_meas_grad_rms_ft_cm }} fT/cm) is a sensitivity analysis.

**Inverse solutions.** Both dSPM implementations use fixed orientations on the same grid, the same noise covariance, a depth exponent of {{ F.meth_dspm_depth }}, λ² = {{ F.meth_dspm_lambda2 }}, a source covariance scaled to the whitened rank and dSPM normalization. They differ in the depth weighting: the study's uses the whitened gains of all of an array's channels, without a limit; MNE-Python's is limited at its default of {{ F.meth_mne_depth_limit }} and uses the unwhitened gains of the gradiometers, or of the magnetometers where there are none (the OPM arrays).

**What the location design allows.** The sign-flip test uses the locations whose difference in detection counts is not zero, and p is smallest when all favour one array: {{ F.meth_signflip_min_p_18 }} with a band's {{ F.meth_locs_per_band }} locations; p < {{ F.meth_alpha }} needs at least {{ F.meth_signflip_min_n }} such locations. With equal differences the test is the exact sign test: of {{ F.meth_locs_per_band }} locations, {{ F.meth_signtest_18_k }} must favour one array for p < {{ F.meth_alpha }} (p = {{ F.meth_signtest_18_k_p }}; with {{ F.meth_signtest_18_kminus1 }}, {{ F.meth_signtest_18_kminus1_p }}) and {{ F.meth_signtest_18_k_holm }} for the first Holm step over {{ F.meth_n_anatomies }} anatomies, p < {{ F.meth_holm_first_alpha }} (p = {{ F.meth_signtest_18_k_holm_p }}); of the confirmatory {{ F.meth_confirm_locs }} ({{ F.meth_confirm_locs_per_stratum }} per orientation stratum), {{ F.meth_signtest_36_k }} (p = {{ F.meth_signtest_36_k_p }}) and {{ F.meth_signtest_36_k_holm }} (p = {{ F.meth_signtest_36_k_holm_p }}). Unequal differences can move p either way (the adult's {{ F.meth_adult_locs_opm }} to {{ F.meth_adult_locs_squid }}: p = {{ F.meth_adult_p }}; {{ F.meth_adult_equal_p }} if equal). Beyond {{ F.meth_signflip_exact_max }} non-zero locations p is estimated from {{ F.meth_signflip_mc_patterns }} random sign patterns (resolution {{ F.meth_signflip_mc_resolution }}). These values follow from the design alone; power, and a minimal detectable S50 ratio, depend on how detection varies between locations and were not computed.
